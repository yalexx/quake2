QuakeII

BaseQ2 · single player

GAME

New Game starts demo1 at the chosen skill. The engine's load/save menus are slot lists this page cannot draw; F9 and F6 are the engine's own quick-load and quick-save keys.

MULTIPLAYER

This box build is single player: its network menus are in the engine but networking is not part of this app.

VIDEO

video mode is the engine's own r_mode list (its 33 modes, then auto and custom); applying restarts the level at that mode. field of view stops at 90 because this build draws no view weapon above it (measured: 91° and up drops the gun). The engine's custom ui scale and the 91–120° field-of-view range are not offered; see docs/presentation-fixes.md.

OPTIONS

Applying restarts the level with the new values; the engine reads them from its own start-up line, not from a visible console. The engine's own menu applies each row immediately; this page needs the apply control because it has only the start-up line. The gamepad row is absent because no gamepad is connected (the engine hides it too).
