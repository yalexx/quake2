VIDEO

video mode is the engine's own r_mode list (its 33 modes, then auto and custom); HD (1280x720) is the default and applying restarts the level at the chosen mode. field of view stops at 90 because this build draws no view weapon above it (measured: 91° and up drops the gun). Applying writes the values into the engine's config.cfg and restarts the level, so they survive later visits.

full screen asks the browser for the whole screen and leaves it on a second tap (or Esc), with the page interface kept. Inside the ClawBox desktop's sandboxed window the browser forbids full screen; there the row reads own window and opens the app in a window that is allowed to fill the display.

game mode (Alt+Enter while the game has the keyboard) is this page's native-game presentation: the game surface alone, every page control hidden, and the page black outside the picture. It asks for full screen on the display the game is on; on a desktop where the Window Management API is allowed it also blacks out each additional display. Esc leaves full screen and the mode. The engine's own vid_fullscreen row is not offered: in this browser build it does not enter full screen, so it was a control that did nothing.

OPTIONS

LIGHTING

RTX look · Performance RTX is on by default (Performance, the preset built for this device's frame budget; High adds the wide light halo). Off returns every light to the engine's original shading. The choice is kept for the next visit.

TOUCH

Applying writes the changed values into the engine's own config.cfg (userdata/baseq2/config.cfg) and restarts the level, so they hold on this and later visits. The engine's own menu applies each row immediately; this page has no console, so it needs the apply control.
